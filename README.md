# Zoek Oswin

Een zoekspel in een toverschool, speelbaar in de browser en installeerbaar als app.

## Op GitHub Pages zetten
1. Maak een repository en upload alle bestanden uit deze map (index.html, manifest.webmanifest, sw.js en de map icons).
2. Ga naar Settings, Pages, kies Deploy from a branch en selecteer de branch main met de map / (root).
3. Open het adres dat GitHub geeft (https://jouwnaam.github.io/repository/).

## Installeren als app
- Android (Chrome): knop Installeer als app op de voorpagina, of menu en dan Toevoegen aan startscherm.
- iPhone (Safari): Deel en dan Zet op beginscherm.
- Computer (Chrome of Edge): installeer-icoon in de adresbalk.

Het icoon op het beginscherm staat in icons/icon.svg. Na het eerste bezoek werkt het spel ook offline.
Verander je iets in index.html, verhoog dan het versienummer in sw.js (CACHE) zodat de nieuwe versie bij spelers aankomt.
